    Using Markdown Viewer as the default app

    Choose Markdown Viewer > Make Default Markdown Viewer…. macOS asks you to confirm the change.

    Or do it in Finder:

    1. Select any .md file and choose File > Get Info.
    2. Under Open with, pick Markdown Viewer.
    3. Click Change All… and confirm.
